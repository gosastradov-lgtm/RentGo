# RentGo — веб-приложение «Прокат оборудования»

Бронирование оборудования, контроль сроков аренды, учёт склада и штрафов.
Стек: **Python 3.10+, FastAPI, SQLAlchemy, PostgreSQL (или SQLite), HTML/CSS/JS без сборщиков.**

## Структура проекта
```
rental/
├── main.py              # бэкенд: модели БД, REST API, расчёт стоимости и штрафов
├── test_rental.py       # автотесты (pytest)
├── requirements.txt     # зависимости Python
├── .env.example         # пример настроек подключения к БД
├── docker-compose.yml   # PostgreSQL одной командой
├── db/schema.sql        # SQL-схема БД (для PostgreSQL и для отчёта)
├── static/              # клиентская часть (отдаётся самим сервером)
│   ├── img/             # загруженные фотографии оборудования
│   ├── index.html
│   ├── css/style.css
│   └── js/              # app.js (роутер), api.js, ui.js, views/*.js (страницы)
└── docs/REPORT.md       # каркас отчёта (требования, ER-диаграмма, тесты)
```

## Быстрый старт (SQLite — ничего дополнительно ставить не нужно)

1. Установите **Python 3.10+** (https://python.org; на Windows отметьте «Add Python to PATH»).
2. Откройте терминал в папке проекта и создайте виртуальное окружение:
   ```
   python -m venv venv
3. Установите зависимости: `pip install -r requirements.txt`
4. Скопируйте настройки: `copy .env.example .env` (Windows) или `cp .env.example .env`
5. Запустите: `uvicorn main:app --reload`
6. Откройте http://localhost:8000. Документация API (Swagger) — http://localhost:8000/docs

При первом запуске приложение само создаст таблицы и заполнит каталог (9 позиций, 3 категории) и двух сотрудников.

## Фотографии оборудования
В панели администратора (вкладка «Админ») в таблице «Склад и тарифы» у каждого товара есть кнопка **«Загрузить» / «Заменить»**: выберите файл JPG, PNG или WebP (до 3 МБ), он сохранится в папку `static/img/` и сразу появится в каталоге. Кнопка «Убрать» удаляет фото, и тогда показывается иконка категории. Рекомендуемый размер — около 800×500 пикселей. Менять фото могут только администраторы, а сервер проверяет тип и содержимое файла.

## Как это работает
- **Доступность**: свободно = всего − в ремонте − списано − сумма броней со статусами «ожидает/подтверждено/выдано», пересекающихся по датам.
- **Стоимость**: число суток (включительно) × количество × цена за сутки.
- **Штраф при возврате**: дни просрочки × количество × штраф за сутки + штраф за повреждение, введённый менеджером.
- **Корзина**: позиции с датами копятся в браузере; при оформлении все брони создаются разом (если хоть одна недоступна, не создаётся ни одна).
- **Ограничение**: бронировать можно не дальше чем на 5 лет вперёд от текущей даты.
- **Статусы**: ожидает → подтверждено → выдано → возвращено; «просрочено» вычисляется автоматически, если оборудование выдано, а срок истёк; клиент может отменить бронь до выдачи.
- **Роли** проверяются на сервере, скрытие пунктов меню в интерфейсе — только удобство.

## Публикация
Любой хостинг с Python (Render, Railway, VPS):
1. Создайте PostgreSQL на хостинге и пропишите `DB_URL` в переменных окружения.
2. Команда запуска: `uvicorn main:app --host 0.0.0.0 --port $PORT`.

## Частые проблемы
- `uvicorn: command not found` — не активировано виртуальное окружение (шаг 2).
- `connection refused` к PostgreSQL — контейнер не запущен (`docker ps`) или неверный порт в `DB_URL`.
- Страница пустая — запускайте `uvicorn` из папки проекта, чтобы сервер нашёл папку `static`.
- Забыли пароль администратора — удалите файл `rental.db` (SQLite) и перезапустите, данные создадутся заново.
